# Bayanaul Geology

Сайт компании Bayanaul Geology — геология, гидрогеология, геодезия и разведка ТПИ по всему Казахстану.

- `index.html` — вся страница (стили и скрипты внутри)
- `media/` — фото и видео с объектов

Чтобы открыть сайт по ссылке: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
