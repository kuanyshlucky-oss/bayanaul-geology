# Bayanaul Geology

Сайт компании Bayanaul Geology — геология, гидрогеология, геодезия и разведка ТПИ.

## Структура
- `index.html` — страница (дизайн и логика)
- `content/` — содержимое, которое редактируется через админку:
  - `news.json` — новости
  - `gallery.json` — фото объектов
  - `services.json` — услуги
  - `settings.json` — телефон, WhatsApp, адрес, соцсети
- `media/` — фото, видео, логотип
- `.pages.yml` — настройки админки Pages CMS

## Как редактировать (админка)
1. Откройте https://app.pagescms.org и войдите через GitHub (аккаунт с доступом к этому репозиторию).
2. Выберите репозиторий и раздел: «Новости», «Фото объектов», «Услуги» или «Контакты и соцсети».
3. Измените и нажмите «Save» — через 1–2 минуты изменения появятся на сайте.

Дизайн и новые разделы меняются в `index.html`.
